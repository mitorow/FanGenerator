# FanGenerator

ブラウザ上で、放射状の扇パターン画像を生成・保存できるシンプルなツールです。
画像サイズ、扇の数、回転角度、配色、中心円の有無などを調整し、オリジナルの背景素材を作成できます。

## デモ

`fan_generator.html` をブラウザで開くと使用できます。

GitHub Pagesなどで公開する場合は、このリポジトリを公開設定にした後、Pagesの公開元に対象ブランチとルートディレクトリを指定してください。

## ファイル構成

- `fan_generator.html`: 生成ツール本体
- `fan_pattern_1920x1920_16segments.png`: サンプル画像

## 使い方

1. `fan_generator.html` をブラウザで開きます。
2. 設定を変更すると、右側のプレビューが自動更新されます。
3. 必要に応じてプリセットまたは「ランダム生成」を使用します。
4. 「画像を保存」を押すと、PNG形式でダウンロードできます。

## 設定項目

- **画像サイズ**: 256pxから2048pxまで、正方形で指定
- **扇の数**: 2個から32個まで指定
- **回転角度**: 0度から360度まで指定
- **色1・色2**: 扇を交互に塗り分ける色
- **中心円**: 中心円の表示・非表示、サイズ、色
- **プリセット**: 旭日旗、白黒、金色、海軍の4種類
- **ランダム生成**: 扇の数、角度、色、中心円をランダムに設定

## ダウンロードされる画像

保存されるファイル名は次の形式です。

```text
fan_pattern_{幅}x{高さ}_{扇の数}segments.png
```

例:

```text
fan_pattern_512x512_16segments.png
```

プレビューは表示領域に合わせて縮小されますが、保存されるPNGは設定した画像サイズで出力されます。

## 動作環境

- JavaScriptとHTML Canvasに対応した最新のブラウザ
- Chrome、Edge、Firefox、Safariなど
- インストールやビルドツールは不要
- 外部ライブラリや外部通信は使用していません
